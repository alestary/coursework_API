# Instapro

MVP социальной сети для обмена фотографиями

## Реализованная функциональность

- Интеграция общей ленты постов с API (динамический рендер)
- Страница добавления поста с описанием и загрузкой изображения
- Страница постов конкретного пользователя (переход по имени в ленте)
- Лайки и снятие лайков с обновлением без перезагрузки страницы
- Счётчик лайков по длине массива `likes` из API
- Относительное время публикации поста («N минут назад»)
- Экранирование HTML в тексте постов (защита от XSS)
- Шапка на всех страницах, включая добавление поста
